Projet personnel · 2026

CalqueLa

Essayez votre tatouage en 3D avant de passer sous l'aiguille.

Une application web qui permet d'essayer un tatouage sur un corps en 3D. On choisit un vrai personnage 3D dans une galerie ou on crée un avatar sur mesure : homme ou femme, taille, corpulence, musculature, visage, teint et coupe de cheveux.

On importe ensuite le dessin d'un tatoueur : le fond est retiré automatiquement, et on garde toutes les couleurs ou seulement le trait noir. Le motif se pose directement sur la peau, à plat ou enroulé autour d'un bras ou d'une jambe, sans limite de taille, et il suit le corps quand on change la pose. Le résultat s'exporte en image et les projets se partagent, sans créer de compte.

  • frontend Three.js + Vite : les tatouages sont peints dans la texture de la peau, par un rendu dans l'espace UV
  • shader de peau à diffusion sous la surface et occlusion ambiante (GTAO)
  • avatar paramétrique construit à partir des données MakeHuman (CC0), avec des morph targets
  • galerie de personnages Microsoft Rocketbox (MIT), animés par leur squelette
  • backend Java 21 / Spring Boot 3, déploiement sur GitHub Pages par GitHub Actions
